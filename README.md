# Node.js & TypeScript Express CRUD API

Bu proje, Node.js, Express.js ve TypeScript kullanarak sıfırdan geliştirdiğim temel bir RESTful CRUD API çalışmasıdır.

## Özellikler
- **GET /api/kullanici**: Tüm kullanıcıları listeler.
- **POST /api/kullanici**: Yeni kullanıcı ekler (Validation kontrolleri dahil).
- **PUT /api/kullanici/:id**: Var olan kullanıcıyı günceller.
- **DELETE /api/kullanici/:id**: Kullanıcıyı siler.

##  Kullanılan Teknolojiler
- Node.js & Express.js
- TypeScript
- tsx (Development Runner)
- Thunder Client (API Testing)
